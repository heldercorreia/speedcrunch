{% trans %}Workspace and history{% endtrans %}

  • {% trans %}Work in tabs and split panes to keep several calculations open side by side.{% endtrans %}
  • {% trans %}Save calculation history between launches and set a history size limit.{% endtrans %}
  • {% trans %}Load your own functions and variables at startup.{% endtrans %}
  • {% trans %}Choose a keypad preset or build a custom keypad.{% endtrans %}
  • {% trans %}Show or hide the main menu. The result display now has a right-click context menu with an entry for the main menu.{% endtrans %}
  • {% trans %}Re-edit an earlier expression and recalculate all the expressions below it.{% endtrans %}
  • {% trans %}Check for updates from within the app.{% endtrans %}

{% trans %}Expressions and editing{% endtrans %}

  • {% trans %}Use lists and matrices in expressions.{% endtrans %}
  • {% trans %}See the interpreted expression alongside the result, with implicit multiplication made explicit.{% endtrans %}
  • {% trans %}Write integer powers with superscript digits.{% endtrans %}
  • {% trans %}Use{% endtrans %} √, ∛, Σ {% trans %}(summation), and{% endtrans %} π {% trans %}as aliases. The{% endtrans %} ~ {% trans %}operator is an alias for{% endtrans %} not().
  • {% trans %}More symbol aliases are accepted for addition, subtraction, multiplication, and division.{% endtrans %}
  • {% trans %}Autocomplete suggestions now show category icons.{% endtrans %}
  • {% trans %}Pasted numbers are automatically formatted to match the global Number Format setting.{% endtrans %}
  • {% trans %}Insert constants and formula book entries with their units included.{% endtrans %}

{% trans %}Results and formatting{% endtrans %}

  • {% trans %}Show a calculation in several result formats at once. Number-format choices include Indian 3-2-2 digit grouping.{% endtrans %}
  • {% trans %}Show rational results as fractions, or use sexagesimal notation for angles and time.{% endtrans %}
  • {% trans %}Show angles as multiples of pi in radian mode or through an explicit conversion.{% endtrans %}
  • {% trans %}Choose how complex numbers are displayed, with polar forms and options for the imaginary unit.{% endtrans %}
  • {% trans %}Set a custom precision with the Custom... option.{% endtrans %}
  • {% trans %}Choose from five rounding modes.{% endtrans %}
  • {% trans %}Changing the primary result format updates only the last expression. Earlier history entries keep their formatting.{% endtrans %}

{% trans %}New functions{% endtrans %}

  • {% trans %}Integer arithmetic:{% endtrans %} powmod {% trans %}for modular exponentiation,{% endtrans %} emod {% trans %}for Euclidean modulo,{% endtrans %} lcm {% trans %}for least common multiples, and{% endtrans %} popcount {% trans %}for counting set bits.{% endtrans %}
  • {% trans %}Number formatting:{% endtrans %} binpad, octpad, {% trans %}and{% endtrans %} hexpad {% trans %}for padded binary, octal, and hexadecimal output. Use{% endtrans %} sci {% trans %}and{% endtrans %} eng {% trans %}for scientific and engineering notation.{% endtrans %}
  • {% trans %}Random numbers:{% endtrans %} rand {% trans %}and{% endtrans %} randint {% trans %}generate random decimals and integers.{% endtrans %}
  • {% trans %}Dates and time:{% endtrans %} datetime {% trans %}and{% endtrans %} epoch {% trans %}convert between date/time values and Unix timestamps.{% endtrans %}
  • {% trans %}Summation:{% endtrans %} sigma, {% trans %}also written as{% endtrans %} Σ.
  • {% trans %}Complex numbers:{% endtrans %} conj {% trans %}for complex conjugates and{% endtrans %} cis {% trans %}for constructing a complex number from an angle. Choose rectangular, exponential, or phasor output with{% endtrans %} rectform, expform, {% trans %}and{% endtrans %} phasorform.
  • {% trans %}IEEE 754:{% endtrans %} ieee754_round_* {% trans %}rounds to a floating-point format, and{% endtrans %} ieee754_*_residual(x) {% trans %}returns the rounding residual. Both families support{% endtrans %} half, float, double, {% trans %}and{% endtrans %} quad.
  • {% trans %}Chemistry:{% endtrans %} molmass, mass, {% trans %}and{% endtrans %} molarity {% trans %}for molar mass, mass from an amount of substance, and solution molarity.{% endtrans %}
  • {% trans %}Linear algebra and data:{% endtrans %} {% trans %}List and matrix support with{% endtrans %} cols, corrp, corrs, covp, covs, cross, det, dot, flatten, inv, norm, rank, rows, shape, trace, {% trans %}and{% endtrans %} transpose.
  • {% trans %}Statistics:{% endtrans %} stdevp, stdevs, varp, vars, {% trans %}and{% endtrans %} mad, {% trans %}with list and matrix support.{% endtrans %}
