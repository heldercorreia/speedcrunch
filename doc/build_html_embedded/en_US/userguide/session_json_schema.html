Session JSON Schema

SpeedCrunch session files are JSON objects with stored calculation history, session-local variables, user functions, user units, and global user-definition startup lines. Session files include a schema identifier so JSON editors and SpeedCrunch can associate them with the current SpeedCrunch session format.

Notes

  • $schema identifies the JSON Schema draft used by the session metadata. SpeedCrunch session files use https://json-schema.org/draft/2020-12/schema.

  • $id identifies the SpeedCrunch JSON Schema for the session format: https://speedcrunch.org/schemas/session-v1.schema.json.

  • session stores the session name. Empty names are normalized to main by SpeedCrunch.

  • limit stores the calculation history limit for the session. A value of 0 means unlimited history.

  • history stores saved calculations. The compact field names preserve the existing session file format: for example xpr is the expression, rst is the result quantity, and ctx is the evaluation context.

  • variables, functions, and units store session-local user definitions. Definitions from global startup user definitions are stored in globals instead.
